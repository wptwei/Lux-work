# 周报 Agent v4.1 安装说明

1. 备份当前 LUX 项目文件夹并停止正在运行的工作台。
2. 解压替换文件包到项目根目录，保留原有目录层级并允许覆盖同名文件。
3. 不覆盖 `data/`、`.env`、个人模型配置或数据库。
4. 在 PowerShell 执行：

```powershell
python -m compileall -q app.py core tests
python -m unittest discover -s tests -q
python app.py
```

如果项目使用 `.venv`，将 `python` 替换为该虚拟环境的 Python 路径。

## 本次重点变化

- AI 先做结构化策划，再逐页创作业务正文。
- 模型失败时显示失败阶段与原因，不再自动把规则草稿作为成品。
- 关键事实未分配、正文出现用户指令、无来源数字/趋势或图表值无来源时会重试或阻止导出。
- 待补充占位符与未确认统计周期会在导出前被拦截；可在正文中修正后重新导出。

## 本地验收

请先在“交付中心 → 周报及文档 Agent”中输入一组包含人力、运营数据、异常事件、本周工作和下周计划的短素材，确认：

- 页面策划中的事实分类正确；背景信息不会被放入本周重点工作。
- 模型成功时，状态显示模型生成的页面数量。
- 停止 Ollama 后，界面会明确提示模型调用失败，正文不会自动替换成本地规则草稿。
- 将“你帮我写”“【待补充：周次】”留在正文中时，Word/PPT 导出会被拦截。
- 只有同一指标具备本期与上期原始值时才生成对比图表。

真实 Windows + Ollama 的生成质量和最终 PPT 页面显示需在目标电脑上确认。
