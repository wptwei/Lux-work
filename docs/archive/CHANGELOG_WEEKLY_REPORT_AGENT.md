# 周报及文档 Agent 更新记录

## v2 内容智能化（2026-10-22）

- 将单次八页生成调整为两阶段：事实分析/页面策划，再生成正文。
- 输入素材生成 F001…事实编号，预览展示每页引用的来源编号和原始事实清单。
- 增加 AI 分析结果的 JSON 结构校验，拒绝不存在的事实 ID 和不完整的页面策划。
- 增加数字、趋势和原因的来源检查；简单差值只在同指标、同单位且计算正确时作为已验证分析。
- 增加导出前核验，手动编辑后若出现无来源数字、趋势或原因，会阻止 Word/PPT 导出。
- 优化周报模块说明和预览卡片，展示页面目的、来源 ID、缺项及质量提醒。
- 测试：108 项自动化测试通过；真实 Windows/Ollama 环境仍需验收。

## v3 PPT 模板映射与动态渲染（2026-10-22）

- 增强历史底版分析，显示每页形状、标题候选、表格、原生图表、图片和占位区。
- 支持页面级占位符与混合映射，新增模板形状名称映射配置。
- 支持结构化图表数据更新原生图表，或在明确的图表占位区创建可编辑柱状图。
- 支持结构化表格数据填充并检查容量；过多条目会明确提示。
- 导出状态显示实际更新的文本框、表格、图表及遗留占位内容提醒。
- 静态图片不被假称已更新；同页多图表仅有一组数据时，只更新一个图表并提示人工核对。
- 标准版输出也支持显式图表数据块，并从普通正文中排除图表/表格数据块。
- 新增 7 项模板引擎测试；全量自动化测试 115 项通过。真实用户模板仍需上传后做最终逐页验收。
