# v4 更新包安装说明

## 推荐方式：替换文件包

1. 先备份正在使用的 LUX 项目文件夹并停止工作台。
2. 解压“仅需替换文件包.zip”到项目根目录，保留原目录层级并允许覆盖同名文件。
3. 不要覆盖 `data/`、`.env` 或用户自行修改的本地模型配置。
4. 在项目根目录运行：

```powershell
python -m compileall -q app.py core tests
python -m unittest discover -s tests -q
python app.py
```

若项目使用虚拟环境，使用该虚拟环境的 Python 解释器。

## 使用动态页数创作

- 在“交付中心 → 周报及文档 Agent”中输入本期素材。
- 点击“分析素材并生成周报”。AI 先整理事实和页面策划，再生成正文。
- 页面数由素材决定，通常建议 6—12 页，不强制；技术边界为 3—20 页。
- 选择“智能创作（自适应页数）”使用内置历史周报风格。
- 选择“历史周报参考创作”并上传一份历史周报 `.pptx`，保留其主题/母版并复用封面固定背景，内容页按本期素材重新生成。
- 历史照片和旧数据页不会直接复用；本期缺少照片时显示待补充占位。
