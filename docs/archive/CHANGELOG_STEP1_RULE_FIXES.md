# 第 1 步补丁：规则修复、出口检查、真实状态文案、事件处置台

## 行为修复
- **风险研判**：“未经授权闯入”“没有刷卡强行开门”“无人陪同闯入”不再被当成否定而降为低风险。
  否定词现在必须与关键词同分句、间隔很短，且间隔里不能出现“经、授权、许可、刷卡、陪同……”（`agents/negation.py`）。
- **紧急程度**：同样支持否定，“确认无人员被困”不再触发“人员被困”。
- **工号规则**：有效的 YYYYMMDD 日期（如 `20261023`）不再被当成工号（`exclude_date_like`，可在配置中关闭）。

## 出口检查
- 新增 `RedlineGuard.check_outbound()`，邮件外发、周报 PPT/Word 导出统一调用，日志只记元数据。
- Word 转 PDF 转换前先做文件名+正文红线检查；`.doc` 需先另存为 `.docx`。

## 真实状态文案
- 页头、快捷栏、隐私卡、当前任务面板不再写死“100% AIR-GAPPED / 业务数据不出域 / 本地模型就绪”，
  由 `core/ui_labels.py` 按 `LUX_MODEL_MODE` 生成（公网模式显示“脱敏后外发”）。

## 事件中心
- “事件处置”（风险/紧急程度/制度研判/人工决定/台账）恢复显示，奖惩匹配改为下方可折叠的“奖惩制度参考”。
- 可用 `LUX_SHOW_INCIDENT_DESK=false` 关闭，回到只显示奖惩匹配。
- 响应时限与责任人若不是来自制度条款，页面标注“系统默认参考值，非制度条款，需部门确认”。
