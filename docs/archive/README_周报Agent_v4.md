# LUX 周报 Agent v4（动态页数创作版）

本版本在 v3 的两阶段内容智能化与模板引擎基础上，结合三份真实历史周报，允许 AI 按本期素材自主决定页数和页面类型。

## 主要更新

- 页数不再固定为 8 页，支持 3—20 页；建议通常 6—12 页，但不强制。
- 支持封面、目录、人力、运营看板、异常分析、重点工作、现场影像、关键节点、管控执行、下周计划、摘要、专题页和结束页。
- 新增历史周报风格配置 `config/weekly_report_style_profiles.json`，并提取不含旧业务数据的封面背景到 `assets/weekly_report_cover_background.png`。
- 历史周报参考创作模式读取上传 PPT 的主题/母版，复用固定封面背景，并重新生成所有内容页，避免旧数据和旧现场照片残留。
- Word/PPT 按实际页数导出；页脚页码按实际总页数动态显示。
- 继续保留事实来源编号、数字/趋势/原因核验和原有 V3 界面风格。

## 本地运行

```powershell
python -m compileall -q app.py core tests
python -m unittest discover -s tests -q
python app.py
```

若使用虚拟环境，请把 `python` 换成项目虚拟环境对应的解释器。

## 推荐工作流程

1. 上传本周工作记录、数据表或输入文本。
2. 点击“分析素材并生成周报”。模型先生成事实清单与页面策划，再生成正文。
3. 检查每页内容、来源编号、缺失信息和数字核验提醒。
4. 选择“智能创作（自适应页数）”直接导出；或上传一份历史周报选择“历史周报参考创作”。
5. 检查 PPT 页面、图片占位和实际数据后再正式使用。

## 注意事项

- 历史照片不作为新一期现场证据复用；没有本期图片时会显示待补充区域。
- 图表只使用明确的结构化数据，不根据普通文字猜测数字。
- “历史周报底版”旧接口仍可用于原页替换，但页数需与模板一致；如需增减页数，请用“历史周报参考创作”。
- 真实 Windows + Ollama 环境仍需在目标电脑上进行最终验收。
