# FRONTEND GLOBAL V3 / 产品级前端规范

## 目标
将异常事件中心 V3 的设计语言推广到 9 个工作模块，而非简单拼接若干风格不同的 UI 卡片。优先保证业务可读、控制清晰和可维护性。

## 基础样式

| Token | 值 | 用途 |
|---|---|---|
| `--lx-background` | `#0c141a` | 页面背景 |
| `--lx-panel` | `#151f27` | 业务面板 |
| `--lx-line` | `#34444c` | 中性描边 |
| `--lx-type` | `#ecf1ed` | 标准内容字色 |
| `--lx-muted` | `#99aeb9` | 辅助信息 |
| `--lx-amber` | `#e8ae70` | 主操作、步骤标识、当前导航 |
| `--lx-mint` | `#9ad6cb` | 正向确认、合规状态 |

- 标题层级：模块标题 `30–44px`，卡片标题 `18–20px`，正文 `12–14px`，代码/英文 overline `9–10px`。
- 结构：左侧固定导航 248px，内容区单列宽度自适应，常用业务采用左右分区并在小屏折叠。
- 交互：按钮、输入、下拉至少约 40px 点击高度；键盘 `focus-visible` 明显；加载/禁用/危险状态独立识别；禁用按钮不可做成可点击装饰。
- 组件：4–8px 小圆角、1px 实线描边、弱阴影；避免漂浮玻璃、彩色光晕、无意义动画。
- 适配：1100px 起改横向导航；760px 下将分区堆叠；480px 下单列指标面板。导航允许自身横向滚动，不允许整个页面横向溢出。

## 工程入口

- `app.py`：Gradio 结构 + `_lux_module_hero()` 纯展示公共头部函数；各 Tab 的 `elem_classes` 是**独立数组**，如 `["lux-module-v3", "lux-module-chat"]`。
- `frontend/lux.css`：唯一实际加载的 CSS；事件中心独立作用域 `.lux-event-v3`；全站新增样式优先使用 `.lux-module-v3`。
- `core/ui_theme.py`：保持原样，读取 `frontend/lux.css`。
- 现有业务函数、数据库与审核权限均不改动。

## 稳定性与兼容

新业务页不得依赖 `nth-child` 匹配表单组件顺序。侧导航由于 Gradio Tab API 不暴露独立导航 ID，维持固定模块序号 1–9；**如果新增或重新排序 Tab，必须同步更新 CSS 与导航验收**。

原则：优先复用 Gradio 6.28.x API，不直接写入内部运行状态；JS 仅服务既有快捷导航，不模拟业务成功。样式修改不得改变按钮 `.click()` 回调及防护逻辑。

## 验收

单元测试只是回归的第一层；运行目标电脑浏览器进行全模块截图比对、页面级横向溢出测试、Tab 切换、滚动、输入及按钮状态检查。任何只基于静态预览的结论不得写成真实 Gradio 验收通过。
