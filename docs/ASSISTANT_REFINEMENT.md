# AI 智能助手专项更新

## 安装
停止 LUX，备份项目。将 overlay 内的内容合并覆盖到原项目目录，再运行 `.\start_web.ps1`，浏览器 Ctrl+F5 刷新。本包累计包含 Deep Space 和首页精修，不是独立项目；保留本机环境、数据库及上传材料。

## 实际修改
- app.py：保留原 respond 流式业务函数，新增 UI 生命周期包装。真实请求期间发送不可用，单次触发防重复提交；结束或异常后恢复。异常可恢复上一条输入，保留正在编辑的草稿。重试需要用户再次发送。
- frontend/assistant.css、core/ui_theme.py：820px 阅读宽度，开放式 AI 回复、轻量用户消息、Markdown 表格/代码内部滚动；继承可增长的输入框和蓝青焦点。加载文案跟随请求，不显示虚假思考或进度。
- frontend/home.css：修复空状态节点导致已有对话被隐藏的选择器。
- frontend/voice_input.js：原 PCM 传输、权限流程及后端 ASR 不变；内联取消录音，释放麦克风、丢弃迟到结果、保留草稿。识别完成提示可编辑后发送；未增加独立转换面板。取消不会强行中断已经运行的服务端推理，但迟到结果不会写入输入框。
- core/library_chat.py、library_retrieval.py：结构化 Markdown 候选列表，显示名称、PDF 类型、版本、匹配依据与下载入口。AI 候选明确标为可能相关，不声称读过正文；没有结果明确说明。
- core/pdf_library.py：目录查询增加现有 owner 字段，供“我上传的资料”按当前账号筛选，不修改数据库结构、文件路由或鉴权规则。
- frontend/workspace.js：对话中的真实文件库链接接入已有预览弹窗，支持读取失败与重试；修复历史样式隐藏聊天内按钮的问题。
- tests：增加发送锁定/恢复、草稿保护、个人上传过滤、录音取消与迟到结果检查。

## 验证结果
63 项针对性 Python 测试通过，涵盖文件检索、PDF 权限、实时语音状态、任务历史、多轮上下文及新 UI 生命周期；Node 模拟 Web Audio 检查通过，包含取消释放轨道及忽略迟到转写；61 项浏览器检查通过，覆盖九页桌面/窄屏导航、真实 HTTP 对话回调、文件下载、对话内预览、预览错误重试、模型错误后解锁及恢复输入。Python / JavaScript / CSS 语法检查通过。

## 验证边界与待处理
本轮不是在用户 Windows 机器上部署。模型和 ASR 使用隔离测试替身，未验证本机模型质量、物理麦克风及浏览器权限弹窗；PDF 已验证实际字节、Blob 与弹窗，Windows 原生 PDF 分页显示仍需本机确认。未新增文件访问历史，因此“上次的报告”只能按现有目录与语义检索给出候选，不假称知道用户上次打开了什么。未添加波形、百分比或模拟成功。对话 API、语音接口和数据库结构保持不变。
