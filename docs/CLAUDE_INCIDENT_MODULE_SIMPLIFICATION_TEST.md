# 异常记录模块精简：实施与验收记录

日期：2026-11-04

## 一、界面变化

- 只保留一个“记录异常”入口：手动填写、听写、语音助手仍复用同一登记服务。
- 记录表单与奖惩表单合并；保存后自动匹配并刷新列表，不再需要主管确认或二次点击。
- 异常台账与奖惩记录合并为“记录列表”，一条事件一行，直接显示当前版本匹配结果。
- 点击列表行打开详情并加载“当前完整正文”，无需输入事件编号；保存即生成新版本并自动重新匹配。
- “补充/更正”并入“编辑记录”，折叠显示修改历史、匹配历史与规则版本、操作留痕。
- 当前匹配结果只展示本轮版本；其他候选、条款原文、旧版本结果折叠，不在主界面展示风险分、紧急度、制度置信度与 Agent 技术信息。
- 匹配失败显示“匹配失败，可重试”，并提供重试按钮；记录本身始终保留。
- 历史独立奖惩记录移入折叠区，不与新事件混淆。

### 搜索、筛选与分页（2026-11-04 追加）

- 关键词搜索：匹配事件编号或当前版本正文，历史版本不会让已更正的记录重新出现在当前结果中。
- 筛选条件：开始/结束日期、来源、匹配状态、记录人（仅 `manage_incidents` 有效）。
- 分页：每页 20 条，显示“第 N/M 页 · 共 X 条”；上一页/下一页自动夹取有效页码。
- 修改筛选条件或点击搜索后回到第一页；刷新保留当前条件与页码。
- 列表点击使用本页快照中的事件编号，不再按行号重新查询，避免新增记录导致行号错位。
- 空结果、无权限和非法日期分别显示明确提示。

## 二、保留与移除

保留：

- 先保存后匹配、失败不丢记录、同一提交重试幂等、同正文可登记多件独立事件。
- 事件版本与修改历史、匹配批次与规则/匹配器版本、条款来源与缺失适用条件。
- 登录认证、记录人权限、脱敏、操作留痕；自动匹配不等于自动扣款或发奖。
- 既有历史事件、奖惩记录、修改历史与相关数据库迁移，不清理、不重置。

移除（用户界面）：

- 主管确认、退回、重新提交、结案操作入口。
- 责任人派发、响应时限、默认多 Agent 分析与完整处置报告入口。
- 主界面的风险分、紧急度、制度置信度、Agent 技术信息。
- 独立奖惩记录表单与事件编号输入式查询。

说明：上述后端函数与历史数据仍保留，供既有接口、历史记录和测试使用；仅停止在精简后的主流程中展示。

## 三、审查问题修复

1. 旧结果误展示：`latest_match` 默认只取当前版本；对话、详情、回执均按本轮版本读取，旧批次不能冒充新结果。
2. 去重错误：前端每次逻辑提交使用稳定编号，失败重试沿用；成功后才清理。同一正文的两次点击各自生成新编号。
3. 更正回退失效：A→B→A 每次保存都生成新版本，不再因正文重复被幂等去重。
4. 旧任务覆盖：任务完成/失败写回同时校验租约与事件版本，迟到旧任务不能改写当前匹配状态。
5. 新规则错标：任务执行前校验规则版本与匹配器版本；不一致时旧任务置为 `stale`，按当前规则重新入队，旧批次保留。
6. 空口令建档：空口令、过短正文、空更正均不生成事件或版本，只提示补充事实。
7. 奖惩展示副本：迟到旧版本回调携带 `incident_version`，版本不一致时直接跳过，不覆盖新正文和新结果。

## 四、修改文件

- `app.py`：精简异常记录页、统一列表/详情/编辑/重试、版本化结果展示、空口令校验；新增搜索、筛选、分页与稳定行编号。
- `core/incident_intake.py`：版本化 `latest_match`、任务版本与租约保护、规则变更重排、重试绕过退避；新增 `search_recent` 检索分页。
- `core/reward_penalty_store.py`：按事件版本保护展示副本，迟到回调不覆盖。
- `frontend/incident_record.js`：稳定提交编号、成功后清理、失败保留记录模式。
- `frontend/lux.css`：搜索行、分页行的桌面与移动端样式。
- `tests/test_incident_intake.py`：失败桩版本对齐、重试任务回收、检索筛选分页。
- `tests/test_incident_regressions.py`：新增审查问题、精简界面、筛选分页与稳定行编号回归测试。
- `tests/test_global_v3.py`、`tests/test_step1_rule_fixes.py`：源码接线断言更新为新入口。

未新增数据库迁移：本次没有表结构变化。既有迁移 `0002_incident_intake.sql`、`0003_incident_versions.sql` 保持不动。

## 五、测试结果

执行：

```bash
.venv/Scripts/python.exe -m unittest discover -s tests -t .
```

结果：`Ran 466 tests ... OK`（退出码 0）。

新增回归覆盖：

- 旧版本奖惩同步回调迟到 → 跳过，不覆盖新正文/新结果。
- 旧版本任务失败 → 不改写新版本匹配状态。
- 同正文两次记录 → 两条独立事件；同一提交编号重试 → 不重复。
- A→B→A 更正 → v3 且正文回到 A，版本历史完整。
- 更正后匹配失败 → 当前区域显示“匹配失败”，不展示旧条款。
- 规则版本变化 → 旧批次保留，新批次标注新规则/匹配器版本。
- 空口令、过短内容、空更正 → 不建档、不生成版本。
- 他人不可读、不可编辑、不可重试。
- 记录→列表→详情→编辑→重试界面数据流。
- 关键词、来源、日期筛选与分页；非法日期提示；点击行使用本页编号快照。
