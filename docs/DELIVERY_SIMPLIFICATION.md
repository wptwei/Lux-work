# LUX 交付中心精简（2026-10-27）

## 页面变化

交付中心主流程调整为：准备素材 → 确认草稿 → 导出文档。

- 顶部只保留标题和一句说明，去掉重复横幅、英文副标题与流程说明。
- 左侧填写工作素材和统计周期，点击“生成周报草稿”。
- 右侧修改草稿，选择“导出 PPT”或“导出 Word”，完成后显示下载入口。
- 从文件导入、模板与参考、策划检查详情、Word 转 PDF、最近生成文档均默认折叠。
- 生成进度、错误、校验提醒仍直接显示，不会因折叠检查详情而隐藏。
- 桌面两栏，窄屏单列；空状态提示和按钮文案缩短。

默认仍使用既有智能创作方式。需要历史周报或空白模板时，展开“模板与参考（可选）”设置。模型模式相关说明也保留在该区域。

## 更新

1. 在 PowerShell 按 Ctrl+C 停止 LUX，备份将覆盖的同名代码文件。
2. 将 overlay 内的内容按目录结构覆盖到项目根目录。
3. 运行 `.\start_web.ps1`，浏览器按 Ctrl+F5 强制刷新。

已有文件库无需重新上传，依赖无需重装。本包包含此前首页精简、文件库和 LLM 检索、语音超时修复的配套代码，适用于当前已安装文件库的项目。

## 保留行为

本次主要修改 app.py 的交付中心组件布局及 frontend/lux.css 的专用样式。与更新前比较，全部顶层业务回调函数保持一致。

原有素材处理、周期检查、模型生成、模板检测、来源核验、PPT/Word 导出、Word 转 PDF、历史版本和权限继续使用既有实现。仅折叠低频界面，不更改业务数据或模型配置。
