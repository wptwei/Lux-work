# 里程碑 C 真机验收方法（唤醒 → 提问 → 回答 → 播报 → 追问闭环）

> 目标：用真实手机验证语音对话闭环——唤醒后自动进入聆听、VAD 判定讲话结束、
> 只提交最终转写、回答通过检查后显示并播报、播放后约 10 秒追问窗口、随时可打断。

## 前置条件

1. 服务已重启，`.env` 已设 `LUX_VOICE_DIALOGUE_ENABLED=true`、`LUX_TTS_ENABLED=true`。
2. ASR 模型已就绪（`models/asr/`，由 install_voice.ps1 下载）、KWS 模型已就绪（install_kws.ps1）、TTS 模型已就绪（install_tts.ps1）。
3. 手机打开公网 share URL（本次为 `https://e26bb48a3b20aee7d2.gradio.live`，重启后会变，读 logs/lux-service-state.json 取最新）。
4. 建议戴耳机测试，以便区分“回声误判”与“正常轮次”。

## 功能验收

### 1. 唤醒后自动进入听取问题状态

1. 点「开启语音助手」，等状态变为「已就绪，喊"小安小安"唤醒」。
2. 说「小安小安」：应听到「我在，请说」（TTS 预合成），随后状态变为「正在聆听…」。
3. 直接说问题（如「帮我介绍一下第7次人口普查」），无需再点任何按钮。

### 2. VAD 判断讲话结束

1. 说完问题后停顿约 1 秒（默认停顿阈值 800ms）：应自动停止录音，状态变为「正在识别…」→「正在思考…」→「正在说话…」。
2. 回答播完后，状态变为「可继续追问…」，此时还有约 10 秒追问窗口。
3. 在窗口内直接说下一句（如「再说得简短一点」）：应作为连续追问自动进入新一轮，无需重复唤醒。

### 3. 只提交 ASR 最终结果

1. 提一个触发红线被拒的问题（如要求输出密钥/用户原文）：界面显示「🚫…」，此时不应播报别的内容；应回到追问或待唤醒，而不是读上一条回答。
2. 空录音：唤醒后不说话，约 8 秒（等待开口超时）应返回「待唤醒」，不产生任何聊天消息。

### 4. 复用现有上下文/检索/权限/输出检查

1. 语音追问「帮我找一下员工考核相关的文件」：应走本地资料检索，回答带来源；语音里不逐字读表格/URL/来源列表。
2. 语音问「刚才说的那个文件，第几条」：应能承接上文（多轮上下文）。

### 5. 回答显示文字并播报

1. 每轮回答：聊天区显示文字，同时手机扬声器播报中文语音。
2. 被红线拒绝的回答：只显示文字，不播报。

### 6. 播放期间不把助手声音识别成问题（回声）

1. 助手播报长回答时保持安静：不应把播报内容识别成新的用户问题（不会自动触发新一轮）。
2. 戴耳机 vs 不戴耳机各测一次，记录是否出现“把助手声音当问题”的误判。

### 7. 约 10 秒追问窗口

1. 回答播完后计时：约 10 秒内说话可继续追问；超过后状态回到「待唤醒」，需要再说「小安小安」才能开始。

### 8. 停止/打断

1. 播报长回答时点「停止 / 打断」：应立刻停止声音，回到待唤醒；旧回答不应继续播。
2. 打断后立刻再唤醒并问新问题：上一轮的结果不应迟到/串台。

## 记录项

### A. 端到端与延迟

- 唤醒应答延迟：说「小安小安」结束 → 听到「我在，请说」第一个字（计 5 次平均）。
- 停顿判定：说完整句 → 到状态变为「正在识别…」的时长。
- 总延迟：说完整句 → 听到回答第一个字（ASR + 模型 + TTS 之和）。
- 冷启动 vs 预热：重启服务后第一轮（含模型加载）与后续各测一次。

### B. 异常场景

| 场景 | 预期 | 实测 |
|---|---|---|
| 无声超时 | 约 8 秒返回待唤醒，无消息提交 | |
| 空录音/咳嗽 | 不提交；提示「没有听清」 | |
| 网络中断 | 提示「网络中断」，不卡死 | |
| 回声（不戴耳机） | 不把助手声音当新问题 | |
| 连续追问 | 窗口内直接说下一句可继续 | |
| 取消/打断 | 立即停止，旧结果不迟到 | |
| 重复问题 | 提示「和刚才一样」，不重复提交 | |

### C. 发音与自然度（沿用里程碑 B 结论）

- 数字/日期/电话/中英混合在「语音对话」上下文里是否仍读对（B 已测，这里抽查即可）。

## 回传结果格式

```
唤醒应答：进入聆听是否自动 __；听到“我在，请说”延迟 __ms
VAD 停顿：判定讲话结束是否及时 __；误提前/漏判情况 __
只提交 final：空录音/红线是否误提交 __
上下文/检索/权限：是否复用且不降级 __
显示+播报：文字与语音是否一致 __；被拒是否只文字 __
回声：是否把助手声音当问题 __（戴耳机/不戴耳机）
追问窗口：约 __ 秒；超时是否回待唤醒 __
停止/打断：能否立即停止 __；旧结果是否迟到 __
异常：无声超时 __；网络中断 __；重复 __
备注：（音色/语速/VAD 阈值是否需要调、特定浏览器表现、是否需换 fp32 TTS 或调整 LUX_VAD_* ）
```

结果回来后，再决定是否调 `LUX_VAD_PAUSE_MS` / `LUX_VAD_SILENCE_TIMEOUT_MS` / `LUX_VAD_ENERGY_THRESHOLD` / `LUX_VOICE_FOLLOWUP_MS`，然后进入里程碑 D（追问窗口、取消与迟到结果隔离的细化）与 E（延迟优化、可选语音打断）。
