# LUX 其余页面精简与美化

更新日期：2026-10-28
基于上一版交付中心精简包，继续调整其余七页。新增修改集中在 app.py 的页面组织、静态提示和 frontend/lux.css 的局部样式。

## 页面变化

| 页面 | 本轮调整 | 保留的操作 |
| --- | --- | --- |
| 运营管理 | 精简标题；系统状态优先；缩小刷新按钮；快捷入口折叠 | 运行状态、任务台账、模块跳转 |
| 效能看板 | 统一指标卡；桌面五列、窄屏两列；精简装饰文字和按钮配色 | 时间范围、任务趋势、效率与安全指标 |
| 事件中心 | 移除大型装饰头图；收紧录入与结果布局；简化等待提示；提升表单可读性 | 现场录入、制度研判、证据、人工决定、事件台账、奖惩条款参考 |
| 资源中心 | 文件搜索置顶；上传、模板维护默认折叠；窄屏搜索框独占一行 | PDF 上传、搜索、下载、版本、回收站、岗位模板 |
| 安全治理 | 精简重复说明和流程装饰；统一筛选栏及核验/审核两栏 | 本机原件核验、审核说明、人工结论及权限检查 |
| 任务历史 | 精简标题和筛选区；优化分页；初始未选择状态改为中性提示 | 类型/状态/岗位筛选、分页、任务详情及评价 |
| 账号管理 | 账号清单优先；新增账号和账号维护折叠；缩小刷新按钮 | 新增账号、角色、重置密码、启停账号及管理员校验 |

保留九个导航入口。不同业务表单并未合并，避免混淆事件处置、文件审核与账号维护的职责。

## 整合依据与范围

- 每页重复的大标题、英文装饰和介绍区改为一个简洁页头。
- 七页共享 lux-refined-page 样式，统一间距、卡片、标题、表格滚动和窄屏规则。
- 低频表单折叠；现有字段、反馈信息、事件绑定及服务端权限校验保留。
- 上传区沿用原 pdf_manage_group 权限输出变量，控制整个上传折叠区；普通用户不会看到空的上传入口。
- 本轮未新增运行依赖、数据库迁移、模型调用或数据处理逻辑。
- 首页、交付中心布局与上一版一致；累计包包含先前文件库、对话检索和语音相关更新。

## 验证与边界

验证明细见压缩包的“验证记录”。自动化测试与浏览器检查在隔离的 Linux 环境完成，浏览器使用临时账号、样例 PDF 和模拟业务记录。

本轮未验证用户 Windows 本机启动、真实麦克风识别准确率、真实 Ollama 模型输出、Office/PDF 转换。也未将文件直接写入用户的 D 盘项目。

旧样式表仍保留历史规则，本轮采用局部样式覆盖以降低影响范围。后续若要整理整个 CSS，可另行做全站视觉回归后删除旧规则。
