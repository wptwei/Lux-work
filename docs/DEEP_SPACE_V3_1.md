## 公共组件与样式来源

- `frontend/design_tokens.css`：补充输入字号、字段间距、面板间距、轻量表面层次及 AI 边界变量。输入边框混色从 78% 调至 62%，与输入背景的对比度为 3.62:1。
- `frontend/lux.css`：实际移除 11 条旧的表单/输入容器填充声明，避免黑色容器重新出现；保留未涉及的兼容布局。
- `frontend/workspace.css`、`home.css`、`assistant.css`：将 66 条涉及分组 `:is()` 的规则展开为普通选择器，消除 Gradio 6.28 作用域处理引起的选择器优先级异常；调整现有首页规则。
- `frontend/page_layouts.css`：新增统一页面骨架、工具栏、表单容器边界及各页信息布局；颜色全部引用 Tokens。普通卡片仅有极弱的表面层次，不使用发光或模糊背景。
- `frontend/precision.css`：完善公共抽屉标题规范。
- `frontend/workspace.js`：历史详情抽屉使用原授权结果；保持原 HTML 源与评价表单在 Gradio 树内。读取成功后才自动打开，避免服务端失败时自动呈现旧结果。
- `app.py`：调整两处展示渲染函数、Gradio 主题容器背景及页面布局声明；给历史选择事件追加仅前端的成功回调。
- `core/ui_theme.py`：接入页面布局层。
- `tools/check_design_tokens.py`：将输入边框、导航选中背景和主按钮 Hover 的混色对比度纳入检查。

## 合并依据与差异保护

容器背景、页面节奏、字号与工具栏属于公共视觉规则；首页 AI 输入、事件录入/研判、文件列表与运营摘要采用不同的信息结构。未把所有页面套为同一套卡片。看板删除的是重复呈现，数据口径和细分数据仍可访问。

业务函数核对：`app.py` 共 99 个顶层函数，本轮仅 `render_dashboard`、`render_operations` 的 AST 发生变化，其余 97 个保持不变。语音采集脚本逐字节不变；API 参数、数据库结构和业务文件内容未更改。历史详情继续调用原有权限校验函数，抽屉不自行查询或重建任务数据。

## 待验证与保留限制

- 本机真实麦克风、Windows 权限、ASR/Ollama 与 Windows Office 转 PDF 尚未在用户电脑验证。模型对话和候选选择在自动化测试中使用确定性替身；文件、索引、数据库与导出使用真实测试实现。
- Firefox、Safari 和屏幕阅读器尚未覆盖。本轮对比度检查不等同于完整无障碍审计。
- Python 测试仍有未关闭事件循环的 ResourceWarning，测试通过；未在视觉升级范围内重构事件循环管理。
- 旧 CSS 兼容层仍保留其他历史布局。本轮完成已识别容器冲突与公共页面规范，不声称清除了所有历史规则。
- 两个参考图临时链接本轮无法读取；视觉实施依据用户九张截图和文字诊断。
- 文件检索仍是现有内容索引与 LLM 候选选择，不冒充完整向量语义搜索；历史交付记录仍不能还原草稿。

## 使用

停止原服务并备份代码，将更新包 `overlay` 内的内容合并覆盖到项目目录，运行 ` .\start_web.ps1 `，浏览器 Ctrl+F5。不要用整个 overlay 文件夹替换项目根目录。本包不包含 `.env`、账号、数据库或业务材料，不需要迁移数据库。

检查命令（项目目录）：

```powershell
.\.venv\Scripts\python.exe -m pip install tinycss2
.\.venv\Scripts\python.exe tools/check_ui_styles.py
.\.venv\Scripts\python.exe tools/check_design_tokens.py
```

`tinycss2` 仅用于开发检查，工作台运行不新增此依赖。
