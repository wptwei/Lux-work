# LUX · Deep Space 渐进升级记录

日期：2026-10-28。基线：上一轮七页美化版本 + 移除侧栏模型卡片补丁。

本轮继续使用原有 Python + Gradio 系统。保留九个业务页面、原有字段、事件回调、API 协议、权限判断及数据库结构。交付的是现有项目的累计覆盖包，不是独立重建的网站。

## 架构审查

| 层次 | 当前实现 | 本轮处理 |
| --- | --- | --- |
| 页面及事件 | app.py 内的 Gradio Blocks / Tabs / 业务回调 | 增加一个布局容器、轻量工具栏及前端初始化绑定，保留原业务控件 |
| 样式 | frontend/lux.css 存在多代规则及独立色值 | 保留兼容布局规则，色值接入变量；新增明确的主题层 |
| 主题加载 | core/ui_theme.py | 按 Design Tokens → 兼容样式 → Workspace 样式加载 |
| 语音 | voice_input.js、core/realtime_voice.py、voice_asr.py | 源码保持不变，验证采集状态及接口传输 |

| 交付业务 | 周报处理及 PPT / Word 导出 | 保持原处理流程；验证实际生成文件 |

## 阶段 1 · Design Tokens

- 修改文件：frontend/design_tokens.css、frontend/lux.css、core/ui_theme.py；app.py 的主题与图表展示色值；tools/check_design_tokens.py。
- 修改内容：集中定义指定颜色、字阶、4px 间距、圆角、布局尺寸与动效时长；旧样式颜色引用兼容变量；增加独立对比度检查工具。
- 视觉改进：统一深空底色、分层面板与蓝青强调，移除旧版分散的橙色主按钮体系。
- 功能影响：三个图表展示函数仅更换颜色表达式，不改变计算或输出数据；其余 91 个顶层函数保持不变。
- 测试结果：CSS 解析和 Python 语法检查通过；33 组允许使用的文字/背景、图形/背景组合通过数学对比度检查。
- 未解决问题：指定蓝色在 Elevated 背景上作为普通小字仅约 4.45:1，因此使用它作按钮填充和图形强调，链接使用青色；未来新增颜色组合需重新运行工具。

## 阶段 2 · 全局布局

- 修改文件：app.py、frontend/workspace.css、frontend/workspace.js。
- 修改内容：新增 232px / 68px 可折叠导航，60px 工具栏，最大 1360px 内容区；导航折叠状态保存在本机浏览器；SVG 线形导航图标保留文字可访问名称。
- 视觉改进：品牌、导航、账号和业务内容分区清晰；已移除的模型信息卡片继续隐藏。
- 功能影响：沿用 Gradio Tabs 切换及选中状态，不实现第二套路由；全部 73 处原事件绑定保留，仅新增一个前端初始化绑定。
- 测试结果：实测侧栏宽度与工具栏高度符合要求；折叠后可跳转；刷新后保留折叠偏好；九页始终只有一个选中入口。
- 未解决问题：需在用户 Windows 浏览器中确认缩放及企业浏览器设置；未进行本机部署。

## 阶段 3 · 公共组件

- 修改文件：frontend/workspace.css。
- 修改内容：统一按钮、输入、搜索、表格、卡片、标签及空状态；提供 Hover、Focus、Active、Disabled 样式，保留 Gradio 的真实加载反馈。
- 视觉改进：表格使用不透明面板；按钮 8px、输入 10px、卡片 12px、大面板 16px 圆角；普通业务列表不发光。
- 功能影响：未更改字段值、校验、提交事件或异步成功条件；表单原有错误、结果和重复提交入口保留。
- 测试结果：九页 448 个可见文字节点的默认状态检查未发现低于对应字号阈值的对比度组合；原生焦点和禁用态继续生效。
- 未解决问题：此检查覆盖当前展示的页面及测试内容，不代表所有未来文档、自定义模板和系统原生弹窗的完整无障碍认证。

## 阶段 4 · 具体页面

- 修改文件：frontend/workspace.css、frontend/workspace.js；app.py 中已失效的“模型状态见顶部”提示改为指向运营管理。
- 修改内容：AI 助手突出输入区和发送；交付中心保持素材/草稿/导出；运营、看板、事件、资源、审核、历史和账号页复用公共样式；文件库增加 PDF 原件预览窗口。
- 视觉改进：保留之前的简洁页头和折叠区；新预览使用统一弹窗、加载状态、错误和重试按钮。
- 功能影响：PDF 预览读取同源鉴权下载接口，校验 PDF 文件头，再用临时 Blob 展示；关闭时释放 Blob 并取消未完成请求。不新增后端接口，不发送文件到模型。
- 测试结果：PDF 下载取得真实 PDF 字节；预览窗口接入真实 Blob；503 错误如实显示，重新加载成功；Escape 关闭后焦点返回预览按钮。
- 未解决问题：无头浏览器不能验证 Windows 内置 PDF 阅读器的最终分页渲染；需在本机浏览器确认，界面保留下载原件作为兼容入口。

## 阶段 5 · 动效

- 修改文件：frontend/workspace.css、frontend/workspace.js。
- 修改内容：Hover 150ms、按压 180ms、弹窗/抽屉 240ms、页面 220ms，统一缓动；支持 prefers-reduced-motion。
- 视觉改进：移除持续背景漂移动画；弱光只用于 AI 核心输入区域，导航与列表以清晰状态变化为主。
- 功能影响：动效不阻断请求、校验或业务完成；界面不计时伪造成功。
- 测试结果：减少动态效果模式下侧栏过渡时长为 0，导航与弹窗仍可操作。
- 未解决问题：未覆盖所有设备 GPU 和系统动效偏好组合。

## 维护方式

新增 UI 颜色只写入 design_tokens.css，组件使用 var(--ds-*)。不要重新添加组件独立色值。

```powershell
.\.venv\Scripts\python.exe tools\check_design_tokens.py
```

旧 lux.css 仍保留兼容布局规则，以保护尚未逐项迁移的历史业务区域；本轮没有宣称清除所有历史重复 CSS。后续可逐模块删除已被覆盖的规则，每次做页面与功能回归。新增组件和页面优先写入 workspace.css，并沿用现有业务回调。
