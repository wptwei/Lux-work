# LUX 首页精简更新（2026-10-27）

## 本轮变化

- 首页顶部改为一行“AI 助手”和一句提示，去掉首页大幅横幅和常驻任务说明。
- 移除右侧常驻技能面板，对话区改为单列铺满宽度；桌面聊天区根据窗口高度调整到 300–520 像素。
- 输入区保留附件、语音和发送。Enter 发送、Shift+Enter 换行保持原有行为。
- 任务类型、启用技能、普通对话、清空对话和区域设置收进“任务类型与设置”。
- 最近任务、结果验收、邮件交付及制作交付物入口收进“任务记录与结果操作”。需要时展开使用。
- 欢迎提示只在空白会话显示，开始对话后消失；清空对话后恢复。
- 保留现有暗色主题，并调整窄屏按钮布局。

第一轮只精简首页。左侧九个业务入口、账号权限及其他页面的业务流程仍保留；未实施此前讨论的五入口导航整合。

## 应用更新

适用于已安装后台文件库的项目。本包累计包含简洁文件库、LLM 文件匹配、语音超时修复，避免覆盖 app.py 后缺少配套模块。

1. 在运行 LUX 的 PowerShell 中按 Ctrl+C 停止服务，备份将覆盖的同名代码文件。
2. 将 overlay 里面的内容按目录结构覆盖到项目根目录。
3. 运行 `.\start_web.ps1`，浏览器按 Ctrl+F5 强制刷新。

无需重新安装依赖，无需重传文件。本包不包含业务数据、账号、密钥或模型文件。

## 修改及兼容

首页修改集中在 app.py 的组件布局及 frontend/lux.css 的首页专用样式。已比较更新前后的全部顶层业务回调，函数代码保持一致。语音传输、文件检索、发送任务、技能切换、任务记录、评价及邮件发送事件仍沿用既有实现。

折叠仅改变显示方式，不会自动发送邮件或执行任务。实际模型和麦克风仍由你本机的配置提供。
