# H区安保周报制作规范（动态页数版）

## 一、历史周报风格基线

参考文件：
- H区八月第四周周报：9 页，包含现场执勤影像、关键节点纪实、管控核心与执行等扩展页面。
- H九月第一周周报：8 页，包含厂区分布&人力分布、专区运营看板、异常汇总分析、本周重点工作、下周计划。
- H九月第二周周报：8 页，沿用九月第一周的主结构，更新运营与异常数据、工作事项和计划。

共同视觉特征：16:9 宽屏、白底、深蓝/蓝色标题、青色点缀、微软雅黑字体、清晰留白、数据看板、现场图片与工作卡片结合；页脚可使用“华东安保二部”，目录页保留“Internal use - confidential”。

## 二、页数和结构原则

- **页数不固定**。根据本期素材数量、主题复杂度和汇报逻辑决定，建议通常 6—12 页，但不强制；3—20 页为技术边界。
- 不得为了达到固定页数添加空白页、重复页或没有事实支撑的内容。
- 常见页面类型：cover、contents、manpower、operations、anomalies、key_work、photo_evidence、timeline、control_core、next_plan、summary、generic、closing。
- 可以新增专题分析、整改闭环、阶段成果、重点项目进度等页面，但必须有输入素材支撑。
- 当某个主题事项较多时应拆分页面，而不是把字体缩小或删掉内容来硬塞进一页。
- 目录页不是必选项；当内容页较少时可以省略。结束页也可按汇报场景决定是否保留。

## 三、内容真实性

1. 数字、日期、金额、人数、结果、责任人和原因必须来自输入素材或明确标注为已验证计算。
2. 没有本期与上期同口径数据时，不得写环比趋势；原因没有来源时不得做归因。
3. 没有上传本期现场照片时，不得把历史周报照片冒充本期现场证据。可以提示“需补充现场照片”，但要明确标注。
4. 图表只允许使用结构化且可验证的数据；不能为了美观补造数值。
5. 对材料不足的地方使用“【待补充：具体字段】”，并在质量提醒中列出。

## 四、动态页面格式

每页以如下格式开始，页码从 1 连续递增：

`## P1 [type:cover] | H区安保周报`

下一行开始写本页正文。页面类型放在 `[type:...]` 中，标题放在竖线后。页面类型应使用已支持的类型之一；不确定时使用 `generic`。

图表数据格式：

`图表数据：`
`类别|本周|上周`
`违禁品携带|27|21`

表格数据格式：

`表格数据：`
`岗位|人数`
`安保岗|22`

图表/表格数据块仅用于渲染，不要在普通正文中重复罗列同一组数字。

## 五、风格和排版

- 主色：#002060；辅助蓝：#1F3B73 / #1F3763；青色点缀：#00B0F0。
- 正文常用灰色：#8C8C8C；次级灰：#7D7D7D；深灰：#2F2F2F；白色：#FFFFFF。
- 中文字体优先微软雅黑，英文和数字可用 Microsoft YaHei / Arial。
- 标题清楚、结论优先；数据页可用 KPI 数字卡、柱状图或折线图；工作事项可用卡片；时间密集的项目可用时间线；管控事项可用模块卡片。
- 页码格式按实际页数动态生成，如 `03 / 09`，不得写死 `/ 08`。
- P4/P5 不再固定绑定特定页码；如果存在运营数据或异常数据，就根据内容类型选择相应页面设计。

## 六、交付前检查

- 页码连续，页数在 3—20 页内；页面标题和内容对应。
- 原始素材中的重要事实有去向，缺失数据明确标注。
- 数字、趋势、原因和 Key Message 有来源支撑。
- 图表使用真实结构化数据；无数据时不创建虚构图表。
- 不残留上期周报的数字、图片、日期或工作事项。
- 检查文本溢出、空白页、占位符、图片缺失与页脚页码。
